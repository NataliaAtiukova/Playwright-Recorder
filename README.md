# Playwright-Recorder (Archived)

Этот репозиторий больше не развивается отдельно.

С 14 мая 2026 Recorder объединен в единый QA-репозиторий:

- Основной репозиторий: [WWB-QA-System](https://github.com/NataliaAtiukova/WWB-QA-System)
- Актуальная ветка: `server-version`

## Что переехало

- API и UI для записи сценариев
- Запуск записанных Playwright-сценариев
- Интеграция с модулем смоков (`smoke-runner`) в одном интерфейсе

## Что использовать сейчас

1. Работайте только через `WWB-QA-System`.
2. Для новых задач и багфиксов открывайте PR туда.
3. Этот репозиторий оставлен как историческая версия.
